# StyleBox

CSS custom `<div>` box maker

## What is StyleBox

StyleBox allows you to make different custom `<div>` for your websites, with adjusting some sliders of:

- width
- height
- rotation
- scale
- skew
- background
- border
- shadow
- and more...

After creating your custom `<div>` you can copy the **HTML** & **CSS** code of it.

## How to Use

Access StyleBox in any device by [clicking here](https://notfaheem.github.io/stylebox/)
