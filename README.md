# StyleBox

CSS custom <code><div></code> box maker

## What is StyleBox

StyleBox allows you to make different custom <code><div></code> for your websites, with adjusting some sliders of:

- width
- height
- rotation
- scale
- skew
- background
- border
- shadow
- and more...

After creating your custom <code><div></code> you can copy the <strong>HTML</strong> & <strong>CSS</strong> code of it.

Access StyleBox in any device by [clicking here](https://notfaheem.github.io/stylebox/)
